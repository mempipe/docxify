# Real-world fixtures

Documents written by real producers, used to check the engine against content it did not generate.

| Files | Producer | Source and license |
| --- | --- | --- |
| `opc-*.docx` | Microsoft Word | [OfficeDev/Open-Xml-PowerTools](https://github.com/OfficeDev/Open-Xml-PowerTools) `TestFiles/`, commit `5881422a881f6ccefce2b9801b5dc6a753670d6e`. MIT, © Microsoft Corporation; see [OPEN-XML-POWERTOOLS-LICENSE](./OPEN-XML-POWERTOOLS-LICENSE). Renamed with an `opc-` prefix only. |
| `python-docx.docx` | python-docx 1.2.0 on its Word-authored default template | Generated by [make_python_docx.py](./make_python_docx.py). python-docx is MIT. |

The `RP*` files are tracked-revision documents. Their `-Accepted` and `-Rejected` variants are Word's own results, kept as a future oracle for accept and reject. `WC001-Digits` and `WC001-Digits-Mod` are a comparison pair.

The engine was also run over the whole upstream corpus, which is not checked in. The [README](../../README.md#real-world-corpus) records how and the result.
